# Threads 7 天貼文（可直接複製）

> **使用規則（先看這段，比貼文本身重要）**
>
> 1. **第一句就要抓人。** Threads 只顯示前兩行，第一行沒鉤子＝沒人點開。
> 2. **不要在正文放連結。** 會壓觸及。連結放「留言第一則」或個人檔案。
> 3. **【】是你要填的地方。** 我沒有你這期的實際關卡資訊，硬填會寫錯，反而毀信任。
> 4. **每天發 1 篇 ＋ 去回 5 篇別人的文。** Threads 是互動平台，只發不回等於沒發。
> 5. **沒單也能發。** 下面所有「戰績」都用**你自己的帳號**或**朋友的帳號**，不要編。
> 6. 發文時間：**晚上 8–11 點**（學生滑手機高峰）。週末下午也不錯。

---

## Day 1（一）｜純乾貨：這期最卡的點

**為什麼發這篇**：建立「這人真的懂」的第一印象。不賣東西。

```
這期深淵最多人卡的不是輸出，是【填入：例如「第二波的行動值」/「某隻王的機制」】。

大部分人的問題是【填入：例如「把大招全砸在第一波」】。

我的做法是【填入：你的實際打法，2–3 句】。

如果還是打不過，通常是【填入：例如「速度不夠，還沒動就被打斷」】。
```

**留言第一則（自己回自己）**：
```
有卡的可以把角色池貼給我，我免費幫你看能不能過，不能過我會直接說。
```

## Day 2（二）｜戰績：用自己帳號做示範

**為什麼發這篇**：證明實力。沒客戶就用自己帳號，完全合法。

```
剛剛用【填入：例如「0 命無專武」】的隊伍把【填入：關卡】打滿了。

【填入：花了幾分鐘】。

最難的是【填入：一個具體卡點】，我試了【填入：幾次】才過。

配置放留言。
```

**留言第一則**：
```
隊伍：主C【】/ 輔【】/ 輔【】/ 生存【】
光錐：【】
重點：【一句話講關鍵】
```

---

## Day 3（三）｜招生：急單（這篇才是廣告）

**為什麼發這篇**：一週只需要 1–2 篇真廣告，這篇就是。用「時間」製造稀缺。

```
今天下午突然空出 3 小時，接一單深淵。

今天打完今天交，滿星才收費，全程錄影。

先私先贏，只接一單。
```

> ⚠️ **只在你真的有空的那天發。** 不要每天發「今天有空」，會被看破，而且會讓你壓力更大。
> 沒空的日子就跳過這篇，改發乾貨。

---

## Day 4（四）｜信任：代打到底會不會被 ban

**為什麼發這篇**：這是你「私訊了但不買」的最大殺手。直面它。

```
最多人問我：代打會不會被鎖？

老實說：會，這是風險，我不會騙你說不會。
代打本來就違反官方條款。

我能做的是把風險壓到最低：
・全程錄影
・不動你的抽卡跟儲值
・不改密碼
・打完提醒你登出其他裝置

如果你完全不能接受任何風險，那就不要委託。
我寧願不接，也不要事後吵架。
```

> 這篇會是你**成交率最高**的一篇。誠實＝專業感。

---

## Day 5（五）｜互動：免費帳號健檢

**為什麼發這篇**：把「看貼文的人」變成「私訊你的人」。這是你的漏斗入口。

```
免費幫看帳號，限 5 個。

你貼角色池，我告訴你：
・這期能不能滿星
・該先練哪隻
・體力該花在哪

不能滿我會直接說不能，不會硬接單。
```

**私訊回覆模板**（有人來就貼）：
```
收到，我看一下。

【判斷結果：可以滿 / 差一點 / 這期不行】

如果只是要打滿，我收 350，滿星才付，全程錄影。
你這隊我可以當天處理，你今天幾點之後有空？
```

---

## Day 6（六）｜定價：為什麼我不便宜

**為什麼發這篇**：把你「心虛降價」的問題反過來，變成品牌定位。

```
有人問我為什麼不做到 100 元。

因為 100 元的代打，通常是「有過就好」。
我接的是「一定要滿星」。

差別在：
・我熟機制，花的時間比一般人少
・不能滿我不接
・打不滿不收錢

所以我寧願一週接 3 單打滿，也不要接 10 單打一半。
```

> 這篇發完，你之後被殺價就有台階下：「你看我上次發過，我不做那種。」

---

## Day 7（日）｜回顧＋名額

**為什麼發這篇**：收尾、製造下週的期待。

```
這週處理了【N】個帳號。

【一句具體心得，例如：這期最多人卡在速度不夠】。

下週我能接的時段：【填入，例如「三晚、日全天」】。
要打的先卡，滿了就等下一期。
```

## 每天必做的 3 件事（比發文重要）

| 動作 | 時間 | 為什麼 |
|---|---|---|
| 回 5 篇別人的貼文 | 10 分 | Threads 靠互動推播，不回沒流量 |
| 檢查私訊、24 小時內回 | 5 分 | 晚回＝單跑了 |
| 追一次「說要考慮」的人 | 5 分 | 這是你最容易被忽略的錢 |

### 追客話術（複製用）
```
嗨～之前你說要考慮，這期結算剩【X】天。
我先幫你免費看一下能不能滿，你截角色池給我。
不能滿我不會硬接。
```

## 一週貼文比例

- 乾貨 / 心得：**4 篇**（Day 1、2、4、5）
- 招生：**2 篇**（Day 3、7）
- 定價／立場：**1 篇**（Day 6）

**不要顛倒。** 你之前會失敗，很可能是「7 篇都是招生」。
