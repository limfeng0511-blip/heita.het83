# 追客話術手冊

> 給「有人私訊、但最後都說要考慮」的你。
> 所有話術都可以直接複製，`【】`換成你的內容。

---

## 0. 先搞懂：他們不買的四個真正原因

| 他嘴上說的 | 他心裡想的 | 你要做的 |
|---|---|---|
| 「我再想想」 | 我不確定你是誰，怕被騙 | 給**免費小樣**＋錄影＋小額試單 |
| 「有點貴」 | 我不知道這值不值得 | 給**比較基準**，不要降價 |
| 「會不會被 ban」 | 我怕帳號出事沒人賠 | **誠實講風險**＋分段付款 |
| 「我再看看」 | 現在又不急 | 給**真實的期限**（結算日） |

**注意：這四個裡面，只有一個跟錢有關。** 你之前直接降價，等於用「錢」去解「信任」的問題——解不動。

---

## 1. 你絕對不能做的 5 件事

1. **不要主動降價。** 一降價，他會想「所以原本是坑我？」而且你會吸引到最愛殺價的人。
2. **不要問「還有需要嗎？」** 這句等於「我要來催你」，對方只會已讀。
3. **不要保證「絕對不會被 ban」。** 一講就露餡，懂的人立刻不信你。
4. **不要一次丟全部價目表。** 選擇越多，越容易「我再想想」。
5. **不要已讀不回就放棄。** 你 0 單，每一個人都很貴。

---

## 2. 開場：免費健檢（你的漏斗入口）

這是你最強的一句，因為**對你是零成本，對他是專業感**。

```
嗨～看到你的訊息了。

我先幫你免費看一下能不能打，你截角色池給我就好。
不能滿我會直接說，不會硬接。
```

**為什麼有效**：
- 「免費」→ 他沒有理由拒絕
- 「不能滿我不接」→ 立刻建立「這人有底線」的印象
- 你順便**篩掉打不過的客人**，不會浪費時間

---

## 3. 報價：只給一個選項

```
我看過了，你這隊可以滿。

我收 350，滿星才付，全程錄影給你。
我這週只剩 2 個時段，你今天幾點之後有空？
```

**三個關鍵**：
1. **只報一個價格**（不要列 14 項）
2. **滿星才付**（把風險從他身上拿走）
3. **問時間**（不是問「要不要」，是問「幾點」——這叫假設成交）

---

## 4. 十個分支，逐一套

---

### 4.1 「太貴了 / 有點貴」

**他真正在想**：我不知道 350 是貴還是便宜，我沒有比較基準。

**不要說**：`那算你 300` ❌（一開口就輸）

**要說**：

```
我懂，350 不是小錢。

不過你可以這樣算：這期深淵的星瓊你現在拿不到，
等於你這一個月少【填入：例如 800 星瓊】。

外面工作室大概收 500–800，我收 350 是因為我自己打、沒有抽成，
而且滿星才付——沒打滿你一毛都不用給。

如果你只是想先試試看，可以先從王棋 150 開始，
打完你覺得可以，再談大的。
```

**為什麼有效**：把「350 元」換算成「你損失的星瓊」，再給一個 150 的台階。

**如果他還是不買**：
```
沒關係，那你先存著。這期結算前如果你想打，再私我，我那時候應該還有時段。
```
（然後放掉，不要纏）

---

### 4.2 「我再想想 / 考慮一下」

**他真正在想**：有一個說不出口的原因。

**不要說**：`好哦，有需要再跟我說` ❌（等於放生）

**要說**：

```
沒問題，慢慢想。

不過我想確認一下，你卡的是價格，還是怕帳號有風險？
如果是後者，我可以先免費幫你打一層，你看完再決定。
```

**這是整本手冊最強的一句。** 因為：
- 你**直接問出真正的原因**
- 而且你**先給了一個免費的東西**，他不好意思不回答

**80% 的人會回**：「其實是怕帳號出事。」
→ 那你就可以接 4.3。

---

### 4.3 「會不會被 ban / 會不會被鎖」

**他真正在想**：出事了我找誰？

**不要說**：`不會啦，我很安全` ❌（一聽就假）

**要說**：

```
老實說：會，這是有風險的，我不會騙你說不會。
代打本來就違反官方條款。

我能做的是把風險壓到最低：
・全程錄影，打完傳給你
・不動你的抽卡跟儲值
・不改你的密碼
・打完提醒你登出其他裝置

如果你完全不能接受任何風險，那就不要委託，我不會硬接。
```

**為什麼有效**：全台灣的代肝都在說「安全、穩定、不鎖」，只有你說實話。
**在一片謊言裡講真話，就是最強的成交。**

**如果他還是不敢**：
```
那這樣，你先從最小的 150 開始，風險你比較能承受。
真的不想也不用勉強，帳號安全本來就該你自己決定。
```

---

### 4.4 「別家比較便宜」

**他真正在想**：憑什麼你比較貴？

**不要說**：`他們是騙人的 / 他們打得很爛` ❌（貶低同行＝沒品）

**要說**：

```
有可能，這市場價格很亂。

我不跟他們比價格，我比這三件事：
・滿星才付，沒滿不收
・全程錄影給你
・當天就能交，不用排隊等

如果你要的是「最便宜、有過就好」，那找他們沒問題。
如果你要的是「一定滿星、當天拿到」，那我這邊比較適合你。
```

**這句的殺傷力在最後兩句**：你把選擇權還給他，反而顯得你不需要求他。

---

### 4.5 「可以便宜一點嗎 / 算我便宜」

**他真正在想**：試探一下，能殺就殺。

**不要說**：`好啦算你 300` ❌（他下次會殺更多）

**要說（不降價，但加值）**：

```
價格我沒辦法降，因為我打一單就是那個時間。

但我可以多送你一個東西：
・免費幫你檢查帳號配置
・或這單多送你一層

你要哪個？
```

**為什麼有效**：你守住價格，但給他「賺到了」的感覺。**加值不等於降價。**

**如果他堅持要殺**：
```
那這樣，你先從 150 的王棋開始，
打得好你再決定要不要打大的。這樣你風險最小。
```

---

### 4.6 「可以打完再付嗎 / 先打後付」

**他真正在想**：我怕付了錢你跑掉。

**要說**：

```
可以，但只限小單（150–250 那種）。
大單我這邊是 30% 訂金，打完確認滿星再補尾款。

因為我這邊是「沒滿星就不收費」，
訂金只是確保我們兩個都不會白忙。
```

**為什麼有效**：你讓步了（小單可以先打後付），但設了界線。**有界線的人看起來比較可靠。**

---

### 4.7 「已讀不回」

**這是最常見、也最容易被你搞砸的一種。**

**絕對不要說**：`還有需要嗎？` / `在嗎？` / `？` ❌

**跟進節奏（重要）**：

| 時間 | 內容 | 目的 |
|---|---|---|
| 第 0 天 | 報價完，**什麼都不做** | 給他空間 |
| 第 2 天 | 給**價值**，不是催 | 讓他想起你 |
| 第 5 天 | 給**期限** | 製造急迫 |
| 結算前 2 天 | 最後一次 | 收尾，然後放掉 |

**第 2 天這樣發**（給價值）：
```
對了，順便跟你說一下，
這期【填入：關卡】最多人卡在【填入：機制】，
如果你是卡在那裡，通常是【填入：原因】。

有需要再跟我說就好。
```
> 完全不提買賣。他會覺得「這人真的懂」，而不是「這人來推銷」。

**第 5 天這樣發**（給期限）：
```
這期結算剩 5 天，我這週還有 1 個時段。
要打的話今天跟我說，不然我就先排給別人了。
```
> 這是**真的**才發。不要編，編一次就毀了。

**結算前 2 天**（最後一次）：
```
明天結算，最後問一次～
要打就現在，不然就要等下一期了。
```

**然後就停。** 不要發第四次。發第四次你就變成騷擾，他會封鎖你。

---

### 4.8 「問很多，但就是不買」

**他真正在想**：我想要免費諮詢，但不想付錢。

**判斷標準**：如果他問超過 5 個問題、還沒提到「多少錢 / 怎麼付」，就是這種人。

**要說（溫和收線）**：

```
你問的這些我都可以幫你，
不過老實說，這些就是我在賣的東西。

這樣好了，你先從 150 的王棋開始，
打一次你就知道我的水準，之後有問題我都免費回答你。
```

**為什麼有效**：你把「免費諮詢」變成「付費入門」，而且價格低到他很難拒絕。

**如果他還是不買**：
```
沒關係，那你有問題還是可以問我，有空我就回。
```
（然後**真的只回短句**，不要再花時間）

---

### 4.9 「我朋友也要，有優惠嗎」

**這是好事**，代表他有信心推薦你。

**要說**：

```
有，兩個人一起的話：
・各打一單，第二單 -50
・或你們同一個時段一起，我一起打，比較快

你要哪個？
```

**注意**：**不要給超過 50 的折扣**，也不要變成「買一送一」。你時間有限。

---

### 4.10 「我現在沒錢，下個月再說」

**他真正在想**：可能是真的沒錢，也可能只是委婉拒絕。

**要說**：

```
了解，不用勉強。

那我先幫你記著，下個月你想打的時候私我，
我幫你留一個老客戶的時段。
```

**然後**：把他記在手機備忘錄，**下個月 1 號主動私他一次**。

```
嗨～上個月你說這個月再看看，
現在有需要嗎？我這週還有時段。
```

**這一步 90% 的人不會做，但它是你最容易撿到的單。**

---

## 5. 成交後 24 小時內要做的事（比成交更重要）

你現在最缺的不是錢，是**評價**。所以每一單都要榨出「證據」。

打完之後，**照這個順序**：

**① 傳成果**
```
打完了，滿星 ✅
錄影在這：【連結】
```

**② 要一句話好評**（不要說「給我好評」，要給他台階）
```
方便的話，可以幫我留一句話嗎？
不用長，一句就好，我想累積一點評價。
```

**③ 要截圖授權**
```
另外想問，這場的戰績截圖我可以放在網站的作品區嗎？
我不會放你的 ID，只放戰績畫面。
```
> 先問，不要自己放。這是基本的尊重，也是專業感。

**④ 給下次的鉤子**
```
下次你要打，直接找我，老客戶價。
```

**⑤ 請他追蹤**
```
我之後會發一些攻略跟實錄，有興趣可以追一下：
【Threads / YouTube】
```

## 6. 前三單特別方案（你現在最該做的事）

你 0 評價，所以前三單的目的**不是賺錢，是換證據**。

```
【首單體驗】前 3 位，半價。
條件只有兩個：
・打完讓我截戰績圖
・幫我留一句話好評
```

**為什麼要「限 3 位」**：
- 有限量 → 有急迫感
- 只有 3 位 → 你不會虧太多
- 有條件 → 不是「便宜」，是「交換」

**⚠️ 但不要寫「免費」。** 免費來的客人不會珍惜，也不會給你真實評價。**半價最剛好。**

---

## 7. 什麼時候該放棄一個客人

符合以下**任兩項**就放掉，不要再花時間：

- [ ] 問超過 5 個問題，沒問過價格
- [ ] 你報價後，他殺價超過 2 次
- [ ] 他已讀不回超過 2 次跟進
- [ ] 他要求「先打後付」＋「大單」
- [ ] 他講話讓你覺得不舒服

**你的時間是你最貴的成本。** 放掉一個爛客，你才有時間接一個好客。

---

## 8. 一分鐘版本（存手機）

如果懶得看上面，只記這四句：

1. **開場**：「我先免費幫你看能不能滿，不能滿我不接。」
2. **報價**：「我收 350，滿星才付，這週只剩 2 個時段。」
3. **他猶豫**：「你卡的是價格，還是怕帳號有風險？」
4. **他不回**：第 2 天給價值、第 5 天給期限，然後放掉。

## 附：可以直接貼的「回頭追客」訊息

針對你之前那些「說要考慮」的人，今天就發這個：

```
嗨～之前你說要考慮，我沒有要催你。

只是這期結算剩【X】天，
我先幫你免費看一下能不能滿，你截角色池給我就好。
不能滿我不會硬接。
```

**這則訊息的目的不是成交，是「重新開啟對話」。**
只要他回你，你就有第二次機會。
