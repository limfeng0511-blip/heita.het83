# 短影音腳本 3 支（不用露臉、不用寫稿）

> **你只需要會剪輯，這三支全部用「遊戲畫面＋大字幕＋BGM」就能做完。**
>
> **【】＝你要填的地方。** 我不硬填遊戲細節，填錯會毀信任。

---

## 通用規則（先看）

1. **前 3 秒必須是「結果畫面」**。不要放 Logo、不要放「大家好」、不要慢慢開場。直接給戰績。
2. **不要講話。** 字幕＋BGM 就夠，而且你之後要重複利用素材更方便。
3. **一支片發四個平台**：抖音 / IG Reels / YT Shorts / 小紅書。零額外成本。
4. **字幕：粗體、白字、黑描邊、字級要大**（手機上看要清楚）。
5. **長度 45–60 秒**，超過 90 秒完播率會掉。
6. **結尾一定有一行字**：「有需要私訊」＋你的帳號。
7. **錄影**：OBS 或顯卡內建錄影，1080p 60fps。**60fps 很重要**，戰鬥畫面才不會糊。

# 第 1 支：代打實錄（主力片，建議一週一支）

**目標**：一眼看懂「這人能打滿」。
**長度**：45 秒

### 分鏡表

| 時間 | 畫面 | 字幕（大字） |
|---|---|---|
| 0–3s | **直接放滿星結算畫面**（三顆星/滿星評分） | `0 命無專武` / `滿星` |
| 3–6s | 切到角色池，快速掃過 | `這是他的帳號` |
| 6–10s | 戰鬥開始，快轉進場 | `開打` |
| 10–35s | 關鍵戰鬥片段（**只留最精采的 2–3 波**，其餘快轉 2×–4×） | 中途只打 2 句：`最卡的是【填入】` / `這裡要【填入】` |
| 35–42s | 打完瞬間、結算 | `【填入】分鐘` |
| 42–45s | 黑底，白字 | `滿星才付・全程錄影` / `有需要私訊` |

### 封面字（三選一）
- `0 命也能滿星`
- `【填入】分鐘打完`
- `這隊居然能過`

### 標題（三選一）
- `0 命無專武，深淵照樣滿星`
- `這期最多人卡的層，這樣打`
- `別人打兩小時，我 40 分鐘`

### 剪輯重點
- **戰鬥段落一律加速**，只留「打贏的那一瞬間」正常速度。
- 轉場用「硬切」，不要用花俏轉場，會顯得不專業。
- BGM 選節奏快的（抖音熱門 BGM 即可）。

> **沒有客戶帳號怎麼辦？** 用你自己的。標題改成「我的帳號」就好，一樣有效。有第一單之後再換成客戶的，會更強。

# 第 2 支：帳號健檢（互動片，導私訊）

**目標**：讓人覺得「我需要他幫我看」→ 直接私訊。
**長度**：50 秒

### 分鏡表

| 時間 | 畫面 | 字幕 |
|---|---|---|
| 0–3s | 一張角色池截圖，**紅圈圈出 3 隻角色** | `這三隻不要練` |
| 3–8s | 鏡頭拉近第一隻 | `【角色名】` / `你已經投太多資源了` |
| 8–18s | 換到正確該練的角色 | `該練的是這隻` / `因為【一句原因】` |
| 18–28s | 快速對比兩張圖 | `同樣體力，差【X】%` |
| 28–40s | 畫面切黑底，列 3 條清單 | `① 【】` `② 【】` `③ 【】` |
| 40–50s | 黑底 | `免費幫看 5 個帳號` / `角色池貼私訊` |

### 封面字
- `這三隻不要練`
- `你的體力花錯了`

### 為什麼這支會成交
因為它**證明你懂**，而且**免費**。看完的人會想「那我的帳號呢？」→ 私訊。

# 第 3 支：代打會不會被 ban（信任片，成交率最高）

**目標**：把「私訊了但不買」的人，變成買的人。
**長度**：60 秒

### 分鏡表

| 時間 | 畫面 | 字幕 |
|---|---|---|
| 0–3s | 黑底白字，超大字 | `代打會被鎖嗎？` |
| 3–8s | 黑底 | `會。` / `這是風險，我不騙你` |
| 8–20s | 黑底，一行一行出現 | `代打違反官方條款` / `任何說「絕對不會」的人都在騙你` |
| 20–38s | 黑底，逐條出現（打勾動畫） | `✓ 全程錄影` `✓ 不動抽卡儲值` `✓ 不改密碼` `✓ 打完提醒你登出` |
| 38–48s | 黑底 | `我能做的是把風險壓到最低` / `不能保證零風險` |
| 48–60s | 黑底 | `不能接受就不要委託` / `我寧願不接，也不要事後吵架` |

### 封面字
- `代打會被鎖嗎`
- `說「絕對不會」的都在騙你`

### 為什麼這支最強
因為**全台灣的代肝都在說「安全、穩定、不鎖」**，只有你說實話。
在一片謊言裡講真話，就是最強的廣告。

## 產能建議（配合你的時間）

你時間破碎，所以**不要追求每天一支**。建議：

| 頻率 | 內容 |
|---|---|
| 一週 1 支 | 代打實錄（主力） |
| 兩週 1 支 | 帳號健檢 或 信任片 |
| 素材 | 每次打單都順手錄，累積起來剪 |

**錄一次，剪三支。** 你打一單 90 分鐘的素材，足夠剪出 3 支短片。
這就是「一邊玩一邊賺」的正確用法——**玩的時候順便錄，剪的時候順便當廣告。**
